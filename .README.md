# Booking Kiosk RSVP & Event Attendance System

Complete RSVP, QR code, and attendance management system built with Node.js, Express, PostgreSQL, and Bootstrap 5.

## Features

- Public RSVP pages via secure unique tokens
- One QR code per confirmed party
- Email delivery via GoDaddy SMTP (Nodemailer)
- Admin dashboard with live attendance stats
- CSV import for invitees
- Mobile QR scanner with duplicate check-in prevention
- CSV exports (register, confirmed, check-ins, declined/outstanding, summary)
- Audit logging, rate limiting, secure sessions
- Render deployment ready

## Local Setup

```bash
# 1. Clone & install
git clone <repo>
cd booking-kiosk-rsvp
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env — set DATABASE_URL, SESSION_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD

# 3. Run migrations
npm run migrate

# 4. Seed admin + default event
npm run seed-admin

# 5. Start
npm start
